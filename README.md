# 🚀 KTA - Kids Tech Academy Website

A modern, responsive, and vibrant website built with **React** & **Vite** for **KTA (Kids Tech Academy)** — inspired by top STEM academies like iSchool and STEM Academy.
🌐 Live Website:
https://ktia-website.vercel.app
---

## 🎨 Features & Sections

- **Header / Navigation**: Sticky translucent navbar with active dropdowns, mobile menu, and quick enroll CTA.
- **Hero Section**: Canvas animated floating particles, energetic headline, statistics counter, floating badge badges, and quick-action category pills.
- **Why Choose KTA (Features)**: Certified instructors, hands-on learning, small class sizes, competitions & events, etc.
- **Courses & Programs**: Interactive cards for:
  - 💻 Coding for Kids (Scratch & Python)
  - 🤖 Robotics Club (LEGO & Arduino)
  - 🎮 Game Design (Unity & GameMaker)
  - 🌐 Web Development (HTML, CSS, JS)
  - 🧠 AI & Machine Learning
  - 📱 Mobile App Development (Flutter)
- **Trainers & Mentors**: Instructor cards with social profiles, bios, and specialties.
- **Fun Facts (Animated Counter)**: Interactive numbers for students, trainers, programs, and learning hours.
- **Gallery**: Filterable photo showcase (Robotics, Coding, Events, Projects) with hover overlays.
- **Latest News & Blog**: Modern article cards with categories and publication dates.
- **Contact & Enrollment**: Interactive enrollment form with instant feedback state, academy address, phone, and opening hours.
- **Footer**: Newsletter signup, quick links, social media channels, and smooth back-to-top scroll button.

---

## 💻 Tech Stack

- **React 19**
- **Vite** (Lightning fast bundling)
- **Lucide React** (Modern clean icons)
- **Vanilla CSS3** (Custom design system, flexbox, grid, animations, responsive breakpoints)

## 🛠️ Local Development

To run the project on your machine:

```bash
cd kta-website
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## ☁️ Deploy to Vercel (Super Easy)

### Method 1: Using Vercel CLI (Fastest)

1. Open your terminal in the `kta-website` folder:
   ```bash
   cd kta-website
   ```
2. Run:
   ```bash
   npx vercel
   ```
3. Follow the simple prompts:
   - Set up and deploy? **Y**
   - Which scope? Select your Vercel account.
   - Link to existing project? **N**
   - Project name: `kta-website`
   - In which directory is your code located? `./`
   - Want to modify settings? **N**

Your website will be live in seconds with a free `.vercel.app` domain!

---

### Method 2: Via GitHub & Vercel Dashboard

1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. If your root is `KidsTech_Gerges`, set **Root Directory** to `kta-website`.
5. Click **Deploy**!
